PROYECTO DESTACADO

Base de datos relacional para una wallet

Un ejercicio de modelado y consistencia de datos aplicado a una billetera digital.
01

Descripción

El desafío consistió en diseñar el modelo de datos relacional de una billetera digital (wallet), donde cada usuario pudiera gestionar sus fondos, realizar transacciones y consultar el historial de sus movimientos.

02

Desafío principal

Garantizar la consistencia de los saldos: evitar que una transacción se pierda o duplique y prevenir que una transferencia interrumpida deje información incoherente. Además, el historial debía ser completo, trazable y fácil de consultar.

03

Solución propuesta

Diseñar un modelo normalizado hasta tercera forma normal (3FN), con entidades para usuarios, billeteras, tipos de transacción y transacciones. El enfoque considera claves primarias y foráneas, restricciones de integridad, transacciones SQL con propiedades ACID e índices para consultas frecuentes. El historial se plantea como un registro de solo agregado: los movimientos no se editan ni se eliminan.

04

Herramientas técnicas

SQL, un motor de base de datos (por definir según la implementación), una herramienta de diagramación entidad-relación y Git/GitHub para el control de versiones del esquema.

SQLModelo ERACIDGit / GitHub
05

Principales aprendizajes

Modelar datos desde los casos de uso, aplicar normalización e integridad referencial, comprender el manejo de transacciones y la consistencia de los datos, considerar índices para consultas frecuentes y documentar un modelo mediante diagramas.

06

Habilidades técnicas aplicadas

Modelado entidad-relación, SQL (DDL, DML, JOIN y agregaciones), conceptos de transacciones ACID, integridad y validación de datos, y documentación técnica.

✳

¿Por qué elegí este proyecto?

Lo elegí porque representa un avance importante en mi aprendizaje: pasar de pensar en tablas por separado a diseñar una estructura considerando la integridad y consistencia de la información. Sus conceptos también se relacionan con el desarrollo backend y con herramientas como Python y Django.
