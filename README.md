# Portafolio técnico — Caroline Acevedo

Sitio estático en HTML, CSS y JavaScript, preparado para publicarse con GitHub Pages.

## Archivos
- `index.html`: contenido y estructura del portafolio.
- `style.css`: diseño adaptable a escritorio, tablet y móvil.
- `script.js`: menú móvil, año automático y personalización de contacto.
- `assets/`: carpeta para agregar el CV u otros recursos.

## Antes de publicar
1. Abre `script.js` y reemplaza `TU_CORREO@ejemplo.com`, `TU-USUARIO` y `TU-PERFIL` con tus datos.
2. Si quieres enlazar tu CV, copia el PDF a `assets/` y escribe su ruta en `cv`, por ejemplo: `assets/CV-Caroline-Acevedo.pdf`.
3. Revisa las descripciones de los proyectos y agrega los enlaces a sus repositorios cuando estén disponibles.
4. En la sección de métricas del caso de estudio, sustituye “Por medir” o “Por probar” únicamente por resultados que hayas comprobado.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub, por ejemplo `portafolio`.
2. Sube `index.html`, `style.css`, `script.js`, `README.md` y la carpeta `assets` a la raíz del repositorio.
3. En el repositorio, entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/(root)`, y presiona **Save**.
6. Espera a que GitHub Pages publique el sitio. La dirección normalmente será `https://TU-USUARIO.github.io/portafolio/`.

Si el repositorio se llama exactamente `TU-USUARIO.github.io`, la dirección será `https://TU-USUARIO.github.io/`.
